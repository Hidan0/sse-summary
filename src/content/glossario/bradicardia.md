---
termine: Bradicardia
sinonimi: [bradicardico, bradicardica, bradicardie]
breve: Frequenza cardiaca più bassa del normale (adulto < 60 bpm).
---

| | Soglia | Contesto | Fonte |
|---|---|---|---|
| Adulto | < 60 bpm | definizione di base (ABCDE) | [@abcde-note:5] [@tss-c2:5] [@tss-abcde-note:6] [@tss-f:17] |
| Adulto | < 50 bpm | aritmie lente; shock grave | [@2.1:37,39] |
| Bambino | < 100 bpm | definizione nelle note ABCDE (generico "bambini"; vedi tabella per età) | [@abcde-note:5] [@tss-abcde-note:6] |
| Bambino | < 80/min | segnale di pericolo nell'insufficienza respiratoria (esaurimento) | [@2.3:28] [@ped-approfondimenti:4] |
| Neonato | FC < 60/min | con torace che si espande: iniziare le CTE 3:1 | [@ost-manuale:22,23] [@rian-neonatale:1] |
| Feto | – | può essere il primo segno di sofferenza fetale | [@ost-manuale:18] |

- Può essere **fisiologica negli sportivi** o un effetto dei farmaci che regolano il ritmo; spesso si associa a sincope. [@2.1:42] [@abcde-note:5] [@tss-abcde-note:6]
- Nello shock indica lo stadio **grave**. [@2.1:37]

::: dubbio
Il valore normale dell'adulto è indicato come 60-100 bpm nelle note ABCDE [@tss-abcde-note:6] ma come 60-80 bpm nella slide dei parametri vitali. [@tss-c2:5]
:::
